Listen SDR Privacy Policy

Last updated: June 14, 2026

Listen SDR is designed to connect to remote SDR receivers over the internet and play their audio stream on the user's device. The app does not require account registration and does not process payments.

The app is intended to keep user data handling simple and local. It stores only the information needed to connect to receivers, keep user preferences, and save recordings created by the user.

Data the app stores locally

  • Receiver profiles created by the user
  • User settings and accessibility preferences
  • Audio recordings created by the user
  • Receiver history, recent frequencies, and local diagnostics exported by the user

Network connections

The app connects directly to third-party SDR servers selected by the user or discovered through public directories. When connecting, the selected remote server receives the normal network information required for the connection, such as the user's IP address and request headers.

Those third-party receivers are operated outside this app. Their own logging, moderation, or access rules are controlled by the receiver operator, not by Listen SDR.

Credentials

If the user stores a receiver password, the app keeps that secret locally on the device using the platform's secure storage mechanisms.

Analytics and advertising

Listen SDR does not serve advertisements, does not sell user data, and does not use third-party analytics for advertising or tracking.

The iOS app includes Firebase support. In Release builds where Firebase Crashlytics is enabled, crash diagnostics may be sent to Google Firebase Crashlytics to help diagnose app failures. Crash diagnostics are limited to technical failure information and coarse app metadata such as app version and build number; they are not used for advertising. Unsigned local test builds can disable Crashlytics collection.

Data sharing

Listen SDR does not operate its own user account system and does not maintain a central cloud profile for listeners. Outside of direct connections to the SDR servers selected by the user, the app does not send personal listening data to a separate service.
